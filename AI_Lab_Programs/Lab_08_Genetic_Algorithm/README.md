# Lab 8: Genetic Algorithm

## Aim
Implement a genetic algorithm to find a good solution using selection, crossover and mutation.

## Questions / tasks
1. Represent a candidate solution as a chromosome.
2. Initialize a population randomly.
3. Define a fitness function.
4. Select parents based on fitness.
5. Apply crossover and mutation.
6. Track the best chromosome across generations.

## Problem used
Find a 10-bit chromosome containing as many `1` bits as possible.

## How to run
```bash
python main.py
```
Uses only the Python standard library.
