# Artificial Intelligence Lab Programs

This archive contains Labs 1–8. Each lab has its own folder with:
- `README.md`: aim, tasks/questions, and run instructions
- `main.py`: readable Python implementation with comments

## Setup
Python 3.9+ is recommended.
Some labs use NumPy:
```bash
pip install numpy
```

## Labs
1. Linear Regression using Gradient Descent
2. DFS, BFS and A* Search
3. Logistic Regression using Gradient Descent
4. 8-Puzzle, 8-Queens and Tic-Tac-Toe
5. Minimax for Game Playing
6. Single-Layer Neural Network / Perceptron
7. Forward Chaining and Backward Chaining
8. Genetic Algorithm

The examples are designed for learning and lab demonstration, not as production systems.
