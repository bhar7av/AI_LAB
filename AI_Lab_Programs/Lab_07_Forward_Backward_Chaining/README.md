# Lab 7: Forward Chaining and Backward Chaining

## Aim
Implement rule-based inference using data-driven forward chaining and goal-driven backward chaining.

## Questions / tasks
1. Store facts and rules in a simple representation.
2. Infer new facts using forward chaining.
3. Check a goal using backward chaining.
4. Compare data-driven and goal-driven reasoning.

## Example rules
- If A and B are true, then C is true.
- If C is true, then D is true.
- If D is true, then E is true.

## How to run
```bash
python main.py
```
Uses only the Python standard library.
