# Lab 5: Minimax Algorithm for Game Playing

## Aim
Use the Minimax algorithm to select an optimal move in a two-player, zero-sum game.

## Questions / tasks
1. Represent a game as a state and generate legal moves.
2. Identify MAX and MIN players.
3. Assign utility values to terminal states.
4. Use recursion to evaluate the game tree.
5. Select the move with the best minimax score.

## How to run
```bash
python main.py
```
Uses only the Python standard library.
