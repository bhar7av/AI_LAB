# Lab 6: Single-Layer Neural Network (Perceptron)

## Aim
Implement a perceptron for binary classification.

## Questions / tasks
1. Initialize weights and bias.
2. Calculate the weighted sum.
3. Apply a step activation function.
4. Update weights using the perceptron learning rule.
5. Test the model on binary input data.

## How to run
```bash
python main.py
```
Uses only the Python standard library.
