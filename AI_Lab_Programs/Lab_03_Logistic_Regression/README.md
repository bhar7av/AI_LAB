# Lab 3: Logistic Regression Using Gradient Descent

## Aim
Implement logistic regression with gradient descent for binary classification.

## Questions / tasks
1. Implement the sigmoid function.
2. Calculate binary cross-entropy loss.
3. Train the weights and bias using gradient descent.
4. Predict a class using a threshold of 0.5.
5. Print the predictions and training accuracy.

## How to run
```bash
python main.py
```
Requires NumPy: `pip install numpy`
