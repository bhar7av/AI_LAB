# Lab 2: DFS, BFS and A* Search Algorithms

## Aim
Implement Depth First Search (DFS), Breadth First Search (BFS), and A* search in Python.

## Questions / tasks
1. Implement DFS using a stack.
2. Implement BFS using a queue.
3. Implement A* using path cost `g(n)` and heuristic `h(n)`.
4. Compare the paths returned by the algorithms.
5. Explain why BFS finds a shortest path in an unweighted graph, while DFS does not guarantee one.

## How to run
```bash
python main.py
```
Uses only the Python standard library.
