# Lab 1: Linear Regression Using Gradient Descent — From Scratch

## Aim
To implement linear regression using gradient descent from scratch and understand how parameters are updated to minimize the cost function.

## Problem statement
Predict house prices using house size (square feet) and number of bedrooms.

## Questions / tasks
1. Implement multiple linear regression without using scikit-learn.
2. Calculate the mean squared error cost.
3. Update weights and bias using gradient descent.
4. Predict the price of a new house.
5. Observe how the cost changes during training.

## How to run
```bash
python main.py
```
Requires NumPy: `pip install numpy`

## Note
The sample dataset is illustrative and is only for demonstrating the algorithm.
