# Lab 4: Search Strategies for 8-Puzzle, 8-Queens and Tic-Tac-Toe

## Aim
Model classic AI problems as state spaces and use search to find solutions or choose moves.

## Questions / tasks
1. Solve the 8-puzzle with BFS.
2. Solve the 8-Queens problem using backtracking (depth-first search).
3. Choose a Tic-Tac-Toe move using a minimax search.
4. Identify the initial state, goal condition, legal operators, and state transitions for each problem.
5. Discuss why uninformed BFS can be expensive for the 8-puzzle.

## How to run
```bash
python main.py
```
Uses only the Python standard library.
